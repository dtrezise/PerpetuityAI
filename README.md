# Perpetuity AI

Temporary public concept site for Perpetuity AI, a working venture thesis for digital identity rights infrastructure.

The site is intentionally dependency-free and deploys as static HTML, CSS, and JavaScript.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.

## Publication

The root of the default branch is published as the temporary public site.
